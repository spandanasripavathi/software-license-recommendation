ABOUT THE PROJECT

Technology with responsibility.

A Computing Ethics project to make open-source software licensing easier to understand.

Purpose

Software developers may find it difficult to understand the different permissions, restrictions, and conditions in software licenses. This system collects project requirements, compares four common licenses, and explains a possible match using a transparent rule-based approach.

Objectives

  • Recommend a license based on project requirements.
  • Explain MIT, GNU GPL, Apache 2.0, and BSD licenses.
  • Promote copyright awareness and intellectual property protection.
  • Encourage attribution and responsible software distribution.
  • Make license comparison easier for student developers.

How it works

  1. Enter project preferences.
  2. Analyze the answers.
  3. Compare license conditions.
  4. View recommendation and alternatives.
